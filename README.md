# Gacha Simulation System 🎲

This project is a C programming application that simulates a Gacha (random prize drop) game system. It focuses on the application of `Struct` and `Array` data structures to effectively manage player and item data.

---

## 🎮 Features
The system is designed to simulate a realistic gaming experience and includes the following functionalities:
* **Multi-User Support:** Supports 2 users with completely independent data management.
* **Inventory System:** A storage system capable of tracking and counting duplicate items.
* **Gacha Rate:** A probability-based randomization system that categorizes items by rarity grades.
* **Menu System:** A user-friendly menu interface with clear and easy-to-navigate categories.

---

## 💻 Technical Concepts
This program was developed to meet and cover the following course criteria:
- [x] **Basic Syntax:** Proper use of fundamental commands, input, and output operations.
- [x] **Control Structures:** Implementation of conditional statements (Switch-Case, If-Else) and loops (Do-While Loop).
- [x] **Array & String:** Effective management of data sets and character strings.
- [x] **Structure (Struct):** Creation of custom data types for `Item` and `Player` entities.
- [x] **Array of Structure:** Integrating structs within arrays to store and manage complex data.
- [x] **Modular Programming:** Breaking down the program into smaller, manageable sub-functions (User-Defined Functions) and utilizing parameter passing.
